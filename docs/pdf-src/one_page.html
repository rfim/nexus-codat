The product owner owns the definition; the platform checks it. This YAML compiles into SQL checks, expectations, grants and the consent row filter.

product:   insights_cash_flow_monthly
owner:     insights-product-lead@example.com   # signs off
definition: Bank inflows minus outflows, excluding own-account
            transfers and loan drawdowns.
grain:     [customer_id, company_id, currency, month]
reconcile:
  against_sql: SELECT company_id, balance_movement ...
               FROM {silver.bank_balance}
  measure:   net_movement_all
  tolerance: 0.01
access:
  read:          [grp_insights_api, grp_risk_analysts]
  tenant_column: customer_id       # row filter on every read
change: {breaking: owner_approval}  # blast radius on the PR

Delta MERGE · src/nexus/bronze.py
Bronze is written by MERGE, never INSERT, so a replayed sync page changes nothing.

def upsert_bronze(spark, batch, cfg):
    keys, order, target = cfg["merge_keys"], cfg["ordering_key"], cfg["table"]
    # dedupe inside the batch, so a replayed page can't apply twice
    w = Window.partitionBy(*keys).orderBy(F.col(order).desc())
    latest = batch.withColumn("_rn", F.row_number().over(w)).filter("_rn = 1")
    cond = " AND ".join(f"t.{k} = s.{k}" for k in keys)
    (DeltaTable.forName(spark, target).alias("t")
        .merge(latest.alias("s"), cond)
        .whenMatchedUpdateAll(condition=f"s.{order} > t.{order}")  # newest wins
        .whenNotMatchedInsertAll()
        .execute())
