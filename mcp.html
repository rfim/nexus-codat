Enabling MCP. One message at a time.

An agent connects to the nexus-insights server, discovers four read-only tools, and asks a question. The semantic layer compiles it, the consent filter scopes it to the caller's customer, and gold answers with a citation, or the request is refused.

Press Play to enable MCP.

    The messages follow the MCP JSON-RPC shapes (initialize, tools/list, tools/call). Tool names, schemas, SQL and rows are the real ones from src/nexus/mcp_server.py, computed in your browser from the run's exported gold tables.

    Ask it yourselfsame tools, same consent filter

    Now you ask. It answers as you.

    A small rule-based planner stands in for the LLM, so answers are deterministic. In CI, the same questions run through the Python MCP server as an eval set (evals/questions.yml).

    In Lifepal, these were insurers. Northbank and Brightpay play the part insurers played in Lifepal: each sees only the SMBs that shared their data with it.
    Try asking as Brightpay about C-101: Brightpay has no consent for it, so the answer is empty. Ask about C-112: its consent was revoked in September. Ask about gross margin: it isn't certified yet.

    Enable it in your client

    # Claude Code, from a clone of this repo
claude mcp add nexus-insights \
  --env NEXUS_CALLER=analyst@northbank.example \
  -- python -m nexus.mcp_server

# or any MCP client, as JSON
{ "mcpServers": { "nexus-insights": {
    "command": "python", "args": ["-m", "nexus.mcp_server"],
    "env": { "PYTHONPATH": "src", "NEXUS_CALLER": "analyst@northbank.example" } } } }

    Over stdio the caller comes from the environment; over HTTP it would come from the token, and the consent filter would be the same.

    Pick a question or type one.

    Why this shapedesign commitments

    Grounded

    Answers come from certified metrics, so an agent can't invent a definition.

    Permissioned

    Every query runs as the caller. No broadly privileged service principal: that route turns every control into decoration.

    Cited

    Every answer names its metric, product version, freshness and contract results.

    Evaluated

    The question set runs in CI: values, tool choice, citations, consent and refusals.
