Land, conform, prove, then publish.

Each task below is a step of src/nexus/pipeline.py, the same entry point a Databricks job calls. Durations are from the run on a laptop-sized Spark session.

01 · Landsrc/nexus/bronze.py

Replay every feed. Nothing changes.

Each system re-sent its last sync page (60 records). Bronze is written by MERGE on the source key, newest sync sequence wins, so the replay is a no-op.
